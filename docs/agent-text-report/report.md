# 模型基础能力：既有实验结论

整理日期：2026-10-21。数据来自2026-10-11的v6.5实验；本次没有新增模型测试。

## 基本结论

1. **菜单菜名能译对，属性仍会猜测。** 既有规则与Agent复核中，120项菜名含义均可接受；40项未注明辣度的菜品被模型标为“不辣”。该结果不是专业译者盲评，也不代表开放场景准确率。
2. **推荐第一次不够稳定。** 10例中首次只有6例同时满足菜单、数量、已给忌口和预算；4例首次超预算。另有组合正确、解释金额错误的情况。
3. **检查程序能修正本批错误，但不代表模型自身已掌握。** 推荐系统最终10/10符合旧约束；其中包括程序拒绝、模型重试及程序计算。模型原始能力和系统效果必须分开评价。
4. **现有数据不足以评价跨场景基础能力。** 尚未实测自然分流、药品、化妆品、食物标签、路牌、通用总结或常用语；也不能据此决定一定要微调或工程已经足够。

## 实验与指标

模型：Qwen3.5-35B-A3B API，温度0，输出上限4,096 tokens。45例：20翻译、10菜品推荐、10票务、5问答。翻译为20张重复模板菜单、6类菜品、18种原文表达；推荐的菜单和用户条件事先正确给定。

| 指标 | 定义 | 模型首次提交 | 系统最终产物 |
|---|---|---|---|
| 菜名含义可接受 | 既有复核判断含义正确的菜名÷120项 | 120/120 | 120/120 |
| 未知信息正确标记 | 辣度、完整配料标记符合来源的项目÷120项 | 80/120 | 120/120 |
| 推荐组合合规 | 菜品/数量合法、满足给定忌口且预算内的案例÷10例 | 6/10 | 10/10 |

**模型首次提交**是未经该次程序校验的草稿；**系统最终产物**经过规则纠错、必要时让模型重试。它们是同一模型在不同处理阶段的结果。旧版百分制仅为检查项量表，不再作为基础能力总分。

## 长度与截断

- 129次调用，单次输出平均216.3 tokens，最大411，上限4,096；接口日志长度上限截断0/129。
- 模型末轮说明平均237.8字符；系统整理后的回复平均132.3字符，最长259；不含单独展示的菜单/卡片。
- 末轮说明可能已经经过工具反馈，不等于首次提交。字符与token不同，token包含工具参数。回复变短不等于模型被截断。
- 本批仅为短输出；长输入、长输出、界面隐藏和自然输入分流没有完成测试。

## 下一轮怎么评价

用新盲测样本，分别测自然分流、来源事实支持率、关键事实覆盖、关键错误、数值与解释一致性，以及推荐和常用语专属指标。先测无纠错模型，再对照给定知识、检索和检查程序；以人工核定证据和确定性规则为评分依据。详见[细粒度评测方案](evaluation-design.html)。
