一、研究目标与可行性结论

本评测研究模型在自然用户输入下的基础能力：能否识别任务，准确归纳来源信息，解释信息及其适用条件，并形成符合要求的推荐或沟通表达。主结果取未经检查程序修改的原始输出；程序纠错后的系统结果作为独立对照。

该目标可以进行有统计依据的测试，首轮也可以控制在常规项目预算内。建议使用200条独立盲测样本，预算约1.6万元，周期约7–10个工作日。这一规模能够形成带置信区间的总体基线并发现主要错误，但不足以精确评价每个细分场景，也不足以证明罕见高风险错误已经消失。若只投入3,000–5,000元，宜先开展50条左右的探索性试测，其结论应限于问题发现。

“严谨”在此指测量对象、证据、判定规则、抽样和误差范围均可检查、可复算。它不意味着所有语义判断都能由程序自动完成。确定性的数值与约束由程序核验；语义、专业含义和歧义由依据明确的双人标注及专家裁定处理。模型可以辅助提取待核验内容，但不直接产生最终标准答案。

设测试样本为用户输入、证据和任务标准的集合。用户输入保留实际表达，不要求用户先选择“总结”“推荐”等分类。参考标准包括允许的处理动作、应覆盖的事实、关键事实、外部证据及可验证的约束；它是评分端的数据，不进入基础模型的输入。

应先界定待评价的来源库和使用条件，再在各层随机抽取。若只能获得方便收集的材料，则结果应称为该测试集上的表现，置信区间也不能消除来源选择偏差。真实业务分布未知时，不把人工配置的任务比例解释为线上请求比例。

为控制首轮成本，样本限定为一张图片及一个短请求，来源通常为单页或局部标签，每题约6–10条必需事实。药品任务评价标签归纳、警示理解与沟通，不评价个性化诊疗；化妆品任务评价来源解释和给定属性比较，不以成分存在推断整品功效。完整长说明书、多轮个性化推荐和复杂现场交通决策应另立实验，不包含在本轮预算内。

参考标准由两名标注者在未查看模型输出时独立制定，记录证据位置、数值单位、否定、适用对象及条件；争议由第三人裁定，专业项目由领域专家审核。已有参考清单不排斥模型提出的其他正确事实：额外主张仍需查证。重复产品、同模板改价格或同一图片裁切属于同一来源簇，不能据此增加独立样本量。

实验条件分别定义为：M0M_0M0​仅获得自然输入及固定产品提示词；M1M_1M1​额外获得冻结且匹配对象的可靠资料；M2M_2M2​单独开放受限检索；M3M_3M3​单独加入规则检查或失败反馈。主结果取M0M_0M0​。首轮只在M1M_1M1​与人工转写输入上进行小规模配对诊断，完整M2M_2M2​与M3M_3M3​对照不包含在首轮预算内，以免将检索、理解和程序纠错混为一种增益。

三、评价指标的形式化定义

3.1 任务识别与处理动作

分流评价应以可观察的领域、意图和下一步动作作为对象。对明确意图可报告各类F1和混淆矩阵；对存在歧义的请求，应判定模型是否采取了合理行动，而不要求猜中用户尚未表达的意图。例如只上传药盒时，识别物品并询问需求可以正确，不能预设用户必然要求用药建议。

“追问”只有在询问真正缺失且影响结论的信息时才计为正确。应追问子集的追问召回率，与信息充分子集的多余追问率分别报告。若产品没有显式路由标签，则只评价实际动作；额外提示模型输出分类标签的实验应作为诊断探针，不能冒充原产品的分流成绩。

成本主要来自证据建立和结果核验。接口费用按实际模型、图片计费和调用日志结算，不凭模型名称推测价格。下面给出的单价是预算计算假设，不是市场报价；没有启动付费实验或聘用人员。

六、验收与结果解释

最终交付应是每个领域的样本数、分流表现、事实支持率、必需及关键覆盖率、关键错误率，以及推荐/常用语专属结果和置信区间；不使用缺乏依据的跨能力加权总分。每项问题均能回到“用户输入—原始输出—证据位置—判定规则”，抽取成功、失败和部分正确案例展示。

首轮能够回答哪些领域或任务明显薄弱、错误主要发生在分流、识读、信息选择、条件理解还是数值推理，以及提供可靠资料后是否出现可解释的改善。它不能直接证明模型适用于所有场景，也不能以系统纠错后的高分证明基础模型已解决错误。

建议将200条基础评测的初步预算设为约1.6万元，以40条校准的实际工时修订正式预算和排期。若现阶段预算只有数千元，则开展探索性试测，明确不发布精确细分准确率或低错误率承诺。严谨程度取决于证据与实验设计；能够支持的结论精度则受独立样本量和人工核验预算共同约束。

参考方法包括FActScore的事实支持评价、人工摘要评价的实验与统计设计以及NIST的比例区间方法。领域证据仍须匹配产品、地区与版本；文献方法不能替代本项目的实际参考标准。
