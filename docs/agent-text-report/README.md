# 点餐助手文字评测报告

下载本文件夹，双击 **index.html** 离线查看。GitHub 文件预览不会执行 HTML。

报告按五部分组织：**实验设置 → 结果与评分 → 长度与截断 → 实际样例 → 结论**。每类默认展示1例，通过下拉框查看全部45例；原始输入、模型回复和菜单图片可展开查看。

- `index.html`：报告页面。
- `examples.html`：完整样例册，45例可逐例展开，含原始输入、各轮方案与说明、最终回复、评分明细、审查意见及字符/token记录。
- `report.md`：文字版，含9个代表样例。
- `assets/`：页面样式、离线数据、20张原实验合成菜单图。
- `data/cases.json`：45例完整记录与评分。
- `data/integrity.json`：文件SHA-256校验清单。

数据来自2026-10-11的v6.5 Agent API实验，2026-10-13补充文字复核，2026-10-17简化报告呈现。本次仅重写报告，实验数据和分数未变。与本仓库本地模型三任务评测分开统计。
