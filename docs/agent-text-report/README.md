# 点餐助手文字质量实验展示

下载本文件夹，双击 **index.html** 即可离线查看；无需安装依赖或启动服务。GitHub的文件预览不会执行HTML，请先下载。

这是2026-10-11已完成的 **v6.5 Agent API实验**，2026-10-13对文字质量作专项复核。它与本仓库的本地Qwen三任务评测是两套独立实验，数据与分数不合并。

## 展示内容

- 45个完整文字任务：20例翻译、10例菜品推荐、10例票务推荐、5例问答。
- 20张原实验合成菜单输入图，覆盖英、法、西三语。
- 输入、原始首次方案、末轮原始回复、最终结果、评分依据和文字长度。
- 类型筛选、语言筛选、全文搜索、修正案例筛选、详情弹窗、打印报告。
- 30例提供事后客观百分制评分；其余15例展示既有通过性审查，不虚构百分制分数。

## 文件

| 文件 | 用途 |
|---|---|
| index.html | 展示入口 |
| assets/ | 样式、交互、离线数据及20张菜单图 |
| data/cases.json | 45例可追溯数据及统计结果 |
| data/integrity.json | 展示文件SHA-256清单 |
| report.md | 文字版报告 |

准确率限于本批重复模板与固定任务。评分为客观检查项，不代表专业译者或用户偏好盲评。最终结果包含工程纠错，不能解释成模型一次生成的准确率。129次调用无输出上限截断，但未测长文本极限。

上传范围仅为展示所需的合成菜单、文字样例及评分。没有设备会话、访问令牌、内网地址、个人信息或运行环境文件，也没有复制助手源码。
