怎么读这些结果

三个必要区分

  1. 原始首次 ≠ 末轮原始回复

    前者是首次提交的方案，后者可能已经经历工具反馈与重试。

  2. 客观满分 ≠ 语言总体满分

    100 分只表示本量表全部检查项满足，不是人工语言质量或偏好盲评。

  3. 系统结果 ≠ 模型一次生成

    最终内容包含工程纠错、确定性金额计算和格式整理。

TAKEAWAY
